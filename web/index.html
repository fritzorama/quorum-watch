The score

Governance votes cast · 40% + Node uptime · 30% + Discussion engagement · 30% = Total score

Weights are fixed and shown here on purpose — nothing about how a member's score is built is hidden behind the number. A member with no mappable GitHub handle shows that metric as not tracked rather than being penalized for a data gap that isn't their fault.
